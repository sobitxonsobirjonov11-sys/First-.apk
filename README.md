# Seller Hub

Seller Hub — Python/Kivy ilovasi. Android APK GitHub Actions orqali
Buildozer yordamida yig'iladi.

## APK yaratish

1. GitHub repozitoriysida **Actions** bo'limini oching.
2. **Build Seller Hub APK** workflow'ini ishga tushiring.
3. Ish tugagach, **seller-hub-apk** artifact'ini yuklab oling.

Build xatosi bo'lsa, **build-log** artifact'ida oxirgi build xabarlarini
tekshiring.

APK barcha qurilmalarda ishlashini kafolatlash uchun real Android
qurilmada sinovdan o'tkazing.
